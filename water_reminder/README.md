# 喝水提醒

无需构建或账号的 Chrome Manifest V3 扩展。设置每日总饮水量（ml）、开始时间与结束时间，每 30 分钟通过系统通知提醒本次应该喝多少水，设置只保存在本机。

## 安装和使用

1. 打开 `chrome://extensions/`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本目录 `water_reminder`（不要选择仓库根目录）。
3. 将「喝水提醒」固定到工具栏，点击水滴图标。
4. 输入每日目标和提醒时段，开启提醒并点击「保存提醒计划」。
5. 点击「发送测试通知」验证系统通知能正常显示。

默认计划为 **2000 ml，09:00–18:00**。每天重复，无需每天重新开启。修改提醒开关后也需要保存。

### 设置不喝水的休息时间

展开「休息时间，不提醒」，点击「添加休息时间」，设置开始和结束时间。可添加、删除多段休息时间，点击「保存提醒计划」后生效。

- 例如每日 09:00–18:00、目标 2000 ml，添加 12:00–13:00 休息：跳过 12:00 和 12:30，13:00 恢复原有半小时节奏，共 16 次，每次 125 ml。
- 休息开始时间包含在内、结束时间不包含在内；非整点休息结束后，会在原计划的下一个有效提醒时点恢复，不额外插入通知。
- 总量均分到剩余提醒；重叠的休息段按覆盖范围处理，不重复扣除。
- 支持跨午夜休息，如 23:45–00:45；每天按本地钟表时间重复。提醒时段外的休息时间不影响计划。
- 若休息覆盖全部提醒，会提示调整，无法保存。若后台提醒延迟进入休息时间，也会跳过。

### 网页动画提醒

1. 开启「网页动画提醒」，点击「保存提醒计划」，在 Chrome 提示中允许网页权限。
2. 打开一个普通 HTTP / HTTPS 网页，点击插件的「发送测试通知」，即可同时测试网页动画和系统通知。

到点时在最后聚焦的 Chrome 窗口当前网页右下角显示水滴、水杯波浪和气泡动画，以及本次应喝的毫升数。卡片 15 秒后自动消失，也可点击关闭、点击「知道了，去倒杯水」或按 Escape 关闭；按钮只关闭提醒，不记录实际饮水量。重复测试会替换上一张动画卡片。系统设置为减少动态效果时，会显示静态卡片。

网页动画默认关闭，旧设置保持兼容。开启时才请求 HTTP / HTTPS 网页权限，动画仅在提醒时注入，不读取网页内容或发送网络请求。Chrome 内置页面、扩展页面、商店等受限制页面、未授权页面、隐藏页面无法显示动画，会保留系统通知；系统通知权限关闭时，动画仍可独立显示。已有网页无需刷新即可注入动画。

## 分配规则

- 未设置休息时，首次提醒在开始时间 **30 分钟后**，结束时间包含最后一次提醒；设置休息后，落在休息时间内的提醒会被排除。
- 例如 09:00–18:00，共 18 次提醒，前 2 次各 112 ml，其余各 111 ml，合计 2000 ml。
- 若尾段不足 30 分钟，则在结束时间补一次：09:00–10:10 会在 09:30、10:00、10:10 提醒，共 3 次，均分总量。
- 少于半小时的时段仅在结束时提醒一次。
- 支持跨午夜，例如 23:00–01:00 提醒时间为 23:30、次日 00:00、00:30、01:00；开始与结束相同不允许。
- 所有提醒使用整数毫升，余数分配到前几次，确保完整计划合计恰好等于目标；每日目标范围为 1–20000 ml，且至少等于提醒次数。
- 通知中的「累计应喝」是计划累计量，不代表已记录的实际饮水量。
- 在时段中途保存、恢复或启动插件时只安排下一次有效提醒，不补齐已错过的量，也不会重新压缩每日目标。

## 后台与通知

- 使用 `chrome.alarms`，关闭弹窗后仍能提醒；Service Worker 唤醒或浏览器重启时会检查并恢复闹钟。
- Chrome 完全退出、电脑关闭或休眠期间无法发送通知。醒来后，延迟不超过 5 分钟的提醒最多发一次；更旧的提醒跳过，继续未来计划，不集中补发。
- Chrome 可能延迟闹钟，因此提醒不保证秒级准时。参见 [Chrome alarms 文档](https://developer.chrome.com/docs/extensions/reference/api/alarms)。
- 使用电脑本地时间；修改系统时间、时区或夏令时切换后，请重新保存计划以重新对齐时段。
- 测试通知按**已保存**的设置发送，不改变计划。系统通知权限、勿扰模式会影响显示；macOS 可在「系统设置 → 通知 → Google Chrome」检查。
- 每次测试和定时提醒都会创建新的通知 ID，并清理上一条同类通知，避免重复发送只替换旧通知而不再次弹出；重新加载插件后可连续点击「发送测试通知」验证。
- 使用 `storage`、`alarms`、`notifications` 和 `scripting` 权限；网页访问权限为可选，仅用于开启后的动画展示。不读取网页内容、不请求网络。

## 开发验证

使用 Node.js 18 或更新版本，无第三方依赖：

```sh
node --test water_reminder/tests/*.test.mjs
```

在仓库根目录执行。测试覆盖整数分配、时段边界、跨午夜、多段休息与重叠休息、设置校验、暂停与恢复、闹钟丢失、Worker 重启竞争、重复事件、休眠延迟、通知失败、动画触发与通知互相兜底。

加载扩展后还可将开始时间设为当前时间、结束时间设为 1–2 分钟后，保存并关闭弹窗，检查结束时通知和次日计划；然后恢复所需设置。系统级通知显示须在实际设备上验证。
